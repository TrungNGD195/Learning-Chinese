## Hanzi stroke data

The frontend uses **hanzi-writer-data 2.0.1**, originating from
[Make Me a Hanzi](https://github.com/skishore/makemeahanzi) and distributed by
[hanzi-writer-data](https://github.com/chanind/hanzi-writer-data).

Character graphics: Copyright 1999 Arphic Technology Co., Ltd.
Additional data: Copyright 2016 Shaunak Kishore.
These character graphics and stroke data are distributed under the
**Arphic Public License** supplied in the package (`ARPHICPL.TXT`).

`frontend/scripts/prepare-hanzi-data.mjs` copies the original, unmodified JSON
files and license into `frontend/public/hanzi-data/`. Filenames use hexadecimal
Unicode codepoints for portable static hosting. The served data remains unchanged.
The generated folder is excluded from Git and regenerated by `predev` / `prebuild`.
Production deployments must include the generated public assets from the build.

The distribution preserves attribution in `/hanzi-data/NOTICE.txt` and the full
license at `/hanzi-data/ARPHICPL.TXT`; learning cards omit repeated source footers.
Stroke data loads from the application's own origin, one character at a time;
it is not bundled into initial JavaScript and does not require a third-party CDN.

The stroke renderer is application code; the Hanzi Writer JavaScript library
is not used. Unsupported characters remain visible as text with an explanatory
message; their stroke order is never synthesized from a font.
